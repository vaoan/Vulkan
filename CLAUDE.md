# Vulkan

A body of the vaoan constellation, class `next-supabase-mono`, generated by
`themis init` from the starter: a thin Next.js and Supabase monorepo.

It is governed by Themis, the vaoan/Themis repository on GitHub. Lint,
TypeScript and Prettier settings come from the `@vaoan/themis` package; the
files at the root only point at it. Never copy a rule into this repository: a
body adds data in `themis.config.mjs` and its own rules in `eslint.local.mjs`,
and it never loosens a shared rule.

## Layout

- `apps/web`: the Next.js app, one route segment per locale (`es`, `en`).
- `apps/web/src/shared/config/app-name.ts`: the app's visible name.
- `themis.config.mjs`: this body's data for the class configuration.

## Commands

```
pnpm install      install (pnpm and Node versions come from package.json)
pnpm dev          run the web app
pnpm build        build the web app
pnpm lint         eslint with the class configuration, zero warnings
pnpm typecheck    tsc over every app and package
pnpm test         vitest
pnpm test:db      database tests (a placeholder until Supabase is added)
pnpm themis <verb>  the Themis CLI (ci, hook, references, skills, ...)
```

## Rules

Until path-scoped agent rules exist in a folder under .claude, this file is all.

## Git flow

`develop` is the default branch and takes `type/*` branches by squash; `main`
is the release line. PR titles are `type(scope): subject [GH-n]`. The git hooks
in `.husky/` and the checks in `.github/workflows/ci.yml` enforce both.
